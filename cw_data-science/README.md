# Data Science Courseworks (Imperial)

This repository contains solutions for **MATH 60026: Methods for Data Science** courseworks at **Imperial College London (2022-2023).**

- Developed **end-to-end Data Science pipelines** for supervised and unsupervised learning tasks, **manually implementing** all models, data preprocessing, optimization, and evaluation **without reliance on pre-built ML libraries**.
- Crafted **detailed plots**, uncovering **valuable data insights** and **highlighting model performance**.

## Coursework 1: Supervised Learning

- Developed **regression algorithms**: Linear Regression, Lasso, Elastic Net, kNN.
- Developed **classifiers**: Random Forest, Linear SVM, Kernelized SVM.

## Coursework 2: Neural Networks and Unsupervised Learning

- Developed a **modular neural network library** with customizable layers and activation functions.
- Developed **clustering algorithms**: GMM, k-means.
- Applied PCA and NMF for **dimensionality reduction** and **image denoising**, then compared reconstruction quality.
- Conducted tumor gene expression analysis using **spectral graph methods**.
